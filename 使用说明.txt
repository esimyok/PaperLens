PaperLens · 文献智能提炼表格 —— 使用说明
================================================

一、快速开始（推荐：双击 PaperLens.exe）
1. 双击 PaperLens.exe：自动启动本地服务并打开浏览器页面，
   检测到 Zotero 在运行时会自动开启「Zotero 联动」。
   关闭黑色控制台窗口即退出服务。
2. 首次使用点右上角「⚙ 设置」，填入智谱 API Key
   （https://open.bigmodel.cn 免费申请，glm-4-flash 系列免费），点保存。
3. 两种用法：
   - 直接把 PDF 拖进页面（或点击选择）
   - 或在 Zotero 里选中一篇文献，约 2~3 秒后这边自动开始分析
4. 也可以不用 exe：直接双击 index.html 同样能用（拖拽上传不受影响；
   Zotero 联动需要服务在运行）。

二、核心功能
- 表格列：文件名 | 标题 | 作者 | 年份 | 关键词 | 研究问题 | 研究方法 | 数据/样本 |
  主要结论 | 创新点 | 局限性 | 一句话总结 | 状态 | 操作
- 双击任意单元格即可编辑（关键词/作者按逗号分隔），改完自动保存，刷新不丢。
- 关键词以标签形式显示；每行操作：重新分析 / 翻译 / 删除。
- 「翻译」：把标题和一句话总结译成中文，显示在对应单元格内（译：开头的小字）。
- 「筛选工具栏」（表格上方）：
  - 搜索框：按标题/作者/关键词/译文/内容模糊搜索
  - 年份、关键词、状态三个下拉筛选（选项自动来自现有数据）
  - 「清除筛选」一键重置；右上角显示 筛选后/总数
- 「导出 CSV」：UTF-8 带 BOM，Excel 直接打开中文不乱码。
- 数据保存在浏览器 localStorage（key: paperlens_records），仅存本机。
- 文本超过 6 万字符自动截断（保留前 80% + 后 20%）；扫描件（无文字层）会明确提示暂不支持。

二点五、AI 服务商（多选一）
设置面板可选择：智谱 GLM / DeepSeek / 通义千问 / OpenAI GPT / Google Gemini / Anthropic Claude。
- 每个服务商的 Key 和模型分别保存，切换即用；模型可下拉选也可手动输入。
- 旧版配置的智谱 Key 会自动迁移。
- Claude 使用原生接口（浏览器直连）；Gemini 走其 OpenAI 兼容接口。
- 某服务商浏览器直连被 CORS 拦截时：智谱自动切代理模式；其它服务商会自动经本地
  代理转发重试一次，需 node proxy.js 在运行。

二点六、文献问答（对话侧边栏）
- 点右上角「💬 问答」开/收起侧边栏；点击表格任意一行即选中该文献作为问答上下文。
- 提问基于该文献的全文（自动截断），要求 AI 只依据文献回答、不编造。
- 每篇文献的对话独立保存（本次会话内），可一键「清空」。

三、Zotero 联动的一次性设置（重要）
需要 Zotero 开两个开关 + 一个插件：
  1. Zotero 设置 -> 高级 -> 勾选「允许其他应用程序与 Zotero 通信」
  2. 开启「本地 API」（独立开关，你目前就差这一步！）：
     Zotero 菜单 -> 工具 -> 开发者 -> Run JavaScript，粘贴运行：
       Zotero.Prefs.set("httpServer.localAPI.enabled", true)
     然后重启 Zotero。
     （等价操作：设置 -> 高级 -> 配置编辑器，搜索 localAPI，切为 true）
  3. Better BibTeX 插件（你已装好）。若 Zotero 启动时弹
     "Better BibTex startup failed: TimeoutError"，重启一次 Zotero 即可恢复。
都完成后：双击 PaperLens.exe -> 在 Zotero 点选文献 -> 自动分析。
没有 PDF 附件的条目会提示跳过；联动只访问本机 Zotero，不联网上传数据。

四、CORS 兜底：本地代理模式
浏览器直连智谱若被 CORS 拦截，工具会自动切换「代理模式」，此时需先启动本地代理：
  1. 在本目录打开命令行，执行：npm install express
  2. 执行：node proxy.js   （监听 localhost:3001，转发到智谱）
保持该窗口开着，回到页面重试即可。代理模式下每次打开页面会有黄色提示条。

五、常见问题
- 提示「Zotero 本地 API 未开启」：按上面第三节第 2 步开启后重启 Zotero。
- 提示「API Key 无效（401）」：检查 Key 是否复制完整、账号是否正常。
- 提示「请求过于频繁（429）」：免费模型有速率限制，稍等片刻再点「重新分析」。
- 失败的行会显示红色错误信息，可直接点该行「重新分析」重试（自动重试已内置 2 次）。
- PDF 很大时解析需要几秒，状态列会显示「第 x/N 页」进度。
- 完全断网时：解析可完成，但 AI 请求失败并给出清晰报错，不会白屏。

六、v1.1 新增功能
- 引用一键复制：每行「引用 ▾」→ GB/T 7714（国标）/ APA / 整行 Markdown
- 导出菜单：CSV / Markdown 表格 / 备份(JSON) / 导入备份；建议定期备份防丢失
- 数据更安全：全文改存浏览器 IndexedDB（容量大），localStorage 只存表格字段；
  存储空间不足时会弹窗提醒
- 列设置：工具栏「列设置 ▾」自由勾选显示哪些列，默认精简
- 深色模式：右上角 🌙 一键切换，自动记忆
- 统计面板：📊 统计 → 年份分布 + 高频关键词
- 多选合并问答：Ctrl+点击多篇文献 → 侧边栏跨文献对比提问
- arXiv / DOI 导入：输入框粘贴 arXiv 链接自动下载分析；粘贴 DOI 自动导入元数据
  （DOI 只含元数据，需自行上传 PDF 后点「重新分析」）
- 扫描件支持：无文字层的 PDF 自动走 OCR（首次使用需联网加载组件，识别较慢）
- 中断恢复：分析中途关页，重开后该行会标记「已中断」，可重新分析
- 单元格复制：鼠标悬停任意单元格，点右上角 ⧉ 复制内容
- 示例数据：空表状态可一键加载 3 篇真实经典论文试用

七、文件清单
- PaperLens.exe   一键启动（服务 + Zotero 联动 + 自动开页面）
- app.py          exe 的源码（Python，零第三方依赖）
- index.html      主页面（也被 exe 内置打包）
- proxy.js        CORS 兜底代理（支持各服务商通用转发）
- 使用说明.txt    本文件
